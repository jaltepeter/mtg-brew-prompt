# MTG Brew Prompt Generator

A minimal web app that generates random deck-building constraints for Magic: The Gathering. Use it to spark new deck ideas by combining format, budget, rarity, theme, and power-level prompts.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the URL shown in the terminal (e.g. http://localhost:5173) in your browser.

## How to use

1. Click **Generate prompt**.
2. Read the random constraint (e.g. “Build a deck. Format: Commander. Budget: Under $50. Theme: Tribal.”).
3. Use it as a starting point for your next brew.

## Build

```bash
npm run build
```

Preview the production build with `npm run preview`.
